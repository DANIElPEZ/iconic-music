# 🎵 Iconic Music  

**Iconic Music** is a mobile app created for people who want to enjoy **unique and original music**. The app allows users to listen to exclusive tracks and save their favorites for quick access.  

## 🌍 Features  
- 🎧 Stream unique music uploaded directly by the creator.  
- ⭐ Save your favorite tracks to a personalized list.  
- 📱 Clean and modern Flutter-based interface.
